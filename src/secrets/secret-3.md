# Соус к мясу

## Ингредиенты

- 1–2 зубчика чеснока
- 1–2 ч. ложки аджики
- 1/2–1 стакан сметаны
- (майонез)

## Приготовление

1. Очистите и раздавите зубчик(и) чеснока в небольшую ёмкость или прямо в стакан со сметаной.
2. Добавьте аджику.
3. Перемешайте.
4. (Можете добавить майонез по вкусу или для объёма, если сметаны осталось мало.)
5. Итадакимас!
